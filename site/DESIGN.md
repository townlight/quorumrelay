# Site design system

The site uses a civic-records visual language: paper, ink, ruled lines and a restrained vermilion accent. The hero's connected record diagram describes the actual capture-to-application flow; it is an illustration, not a product screenshot.

- Color: warm paper `#f5f3eb`, ink `#142e2d`, accent `#b6432b`, subdued green `#dce8df`, fine rule `#bccbc1`.
- Type: system sans for navigation and body, Georgia for editorial display, system monospace for code. Headings use a responsive scale; prose is limited to 72 characters.
- Space: 4/8/12/16/24/32/48/80px rhythm; 1200px maximum layout width.
- Form: flat surfaces, thin rules, modest 4px buttons; one dark code surface provides contrast.
- Behavior: responsive navigation, an accessible mobile menu, visible focus, reduced-motion support, no external fonts or runtime CDN. Documentation routes are static and work under a project subpath.
- Imagery: generated workflow diagram and actual SDK snippets only; no screenshots or social proof are invented.
