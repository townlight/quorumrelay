CloudCast MRSS

0:00 / 0:54

Media RSS (MRSS) is an RSS extension used for syndicating multimedia files (audio, video, image) in RSS feeds.

To enable MRSS for a CloudCast player:

  1. Login to connect.telvue.com
  2. Under Administration –> VOD Players –> Edit –> Sharing, the MRSS checkbox needs to be enabled to reveal the MRSS feed link.

This MRSS feed includes a “cloudcast” extension that provides the program, episode, summary, and ID of the video. Additionally, we take advantage of the media:group element to list the HLS, RTMP and html5 versions of the video.

By default, the feed will return ALL content, sorted in descending order from the creation time. For content to appear in the feed, it must be In a published playlist, series or category.

You can limit the number of returned videos by specifying a query string parameter “recent“:
The MRSS feed link becomes: https://connect.telvue.com/mrss/Player access key?recent=10
This will show the 10 most recent videos added to your account.
