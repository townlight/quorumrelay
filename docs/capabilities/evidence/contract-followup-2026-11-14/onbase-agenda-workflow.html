The Create or Update Agenda Item from Document action allows you to use an OnBase document or E-Form to add, update, or clear both legacy and Unity Form agenda items in Agenda.

For a specific existing agenda item, you can modify its field values and add additional supporting documents.

When configuring this action, note the following:

  • All necessary items in Agenda must be completely configured.
  • An agenda item should not be created from the same OnBase Document Type that is used to initialize the workflow. If the same Document Type is used to create an agenda item and initialize the workflow, and the Create or Update Agenda Item from Document action is used as a System Task, then an infinite loop is created, resulting in multiple new agenda items.
  • This action is only supported in the Core-based Client and Unity Workflow interfaces.
  • Agenda license is required to configure and use this action.
  • Exporting this action requires a destination database that already contains a meeting type or agenda item type.

This action allows you to configure import types, which allows for the import and export of agenda items to know what types they are, and also allows for the import to map to the corresponding objects in the new system:

  • Agenda Manager Item Types (map only)
  • Agenda Manager Meeting Types (map only)

When configuring these import types, note the following:

  • Prior to importing the workflow, the Meeting Type used by the workflow must exist. The import cannot create a new Meeting Type and Item Type. The import can only map to existing meeting and item types.
  • If a workflow action is configured to target an agenda item for a meeting (pending item), then the Target Meeting must exist in Agenda.
  • In Workflow, the configuration for a Target Meeting uses an ID number. The Target Meeting number will need to be determined, and any actions or rules using the Target Metting in the imported workflow will need to be updated to the correct ID after the import.

The configuration of Create or Update Agenda Item from Document action varies depending on whether you select the Unity Form or the Legacy Form agenda item in the Properties pane. For more information on configuring this action with Legacy and Unity agenda items, see Option: Agenda Item Information Mapping.

CAUTION: When attempting to update Unity Form agenda item, you cannot use the Legacy Form option. When this option is selected, the Agenda Form drop-down list is disabled.
Tip: As a best practice, with Legacy agenda items, this action should only be used as a System Task when you are creating a new Agenda Item and the Agenda Item Primary Key can be set to Constant Value of 0.
