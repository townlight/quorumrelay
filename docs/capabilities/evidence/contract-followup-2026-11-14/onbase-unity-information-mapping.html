The following section outlines the procedure of associating Agenda Item Fields from Unity Form with values from an OnBase E-form or document via Agenda Item Information Mapping option.

CAUTION: When attempting to update Unity Form agenda item, you cannot use the Legacy Form option. When this option is selected, the Agenda Form drop-down list is disabled.

To perform Agenda Item Information Mapping with Unity Form:

  1. In the Properties pane, on the General tab, click Configure.
    The Agenda Item Information Mapping dialog box is displayed.
  2. Select one the following required Agenda Item Fields:
    Note: All the required Agenda Items Fields are marked with an asterisk (*) and displayed automatically in the Agenda Item column.
    Agenda Item Field Description
    AgendaItemType

    Classifies individual agenda items.

    Set it to Constant Value and select agenda item type from the Agenda Item Type drop-down list.
    ShortTitle

    The short title of an agenda item.

    Set it to one of the following:

    • Constant Value - to set a static title for all items created via the Workflow action.
    • Keyword Type - to select a keyword from the form as a title of an agenda item.
    Meeting Type

    The name of the type of meeting the item is associated with. Set it to Constant Value.

    Ensure that any configured Agenda Item Fields are compatible with the selected Meeting Type.

    Agenda Item Fields are configured and assigned to Meeting Types as described in the Agenda documentation.

    OwnershipGroup

    The user group assigned to the agenda item.

    Set it to Constant Value.
  3. To modify Name/Value field of an agenda item, select the agenda item from the Agenda Item column and select one of the following from the Get From drop-down list:
    Value Description
    Constant Value

    Populates selected Agenda Item Field.

    Specify a value in the drop-down list or in the Name or Value field.
    E-Form Field Name

    Populates selected Agenda Item Field.

    Type the E-Form Field Name in the Name or Value field.
    Keyword Type

    Populates selected Agenda Item Field.

    Select a Keyword Type from the Keyword Type drop-down list.

    Keyword Types are assigned to Document Types in the system. The Keyword Type drop-down list displays all the available keywords in the system.

    Note: When an agenda item is created via Workflow, the title of the agenda item is based on a keyword entered for the title on the form that is used to initiate the Workflow action.
    Workflow Property

    Populates selected Agenda Item Field.

    Defined in a life cycle as a part of a Workflow action, rule, or task.

    Type the Workflow Property in the Name or Value field.
    Note: The Constant Value, E-Form Field Name, or Workflow Property cannot exceed 255 characters.
  4. Perform one of the following:.
    • Select a value from the drop-down list to match the item you selected from the Get From drop-down list.
    • Type a value in the Name or Value field if a drop-down list is not applicable.
  5. Click Update.
    The value of the selected agenda item is displayed in the Name/Value column.
    Note: A message box may be displayed, prompting you to ensure that any Agenda Item Fields you have configured are compatible with the selected Agenda Item Type.
  6. Repeat steps4 and 5 to configure the remaining required Agenda Item Fields.
  7. Select any optional Agenda Item Fields from the Agenda Item Field drop-down list and configure them by performing step 4 and clicking Add. If you select one of the following Agenda Item Fields, configure them as shown in the following table:
    Agenda Item Field Value
    Mark Attachment Confidential Constant Value set to 1.
    Closed Session Constant Value set to 1.
    Attachment Exclude from Packet Flag Constant Value set to 1.
    Note: The Agenda Item Fields available from this drop-down list correspond to the Agenda Item Field names that were created using Agenda administration.
  8. Once all the Agenda Item Fields are configured, click OK.
  9. In the Property to Store Agenda Item Primary Key field, type AgendaItemPrimaryKey.
  10. To configure Related Documents, select Attached Related Documents, navigate to the Related tab, and configure one of the following:
    • Portfolio Type
    • Portfolio Relation
    • Ad Hoc Portfolio Relation
    Related documents become supporting documents for agenda items.
  11. Select the Keyword Type from the Keyword Type to Set Related Document Order drop-down list if you want to use the Keyword Type to set the order of supporting documents attached to agenda item.
    Tip: One of the most typically used Keyword Types is Document Handle.
    Tip: It is recommended to check the resulting property value immediately after the Create or Update Agenda Item from Document action is executed by configuring the following rules: Check Last Execution Result and Compare Property Value. Configure the Check Last Execution Result to verify that the Create or Update Agenda Item from Document action occurred. Configure the Compare Property Value rule to use the property value that was set by the Property to Store Agenda Item Primary Key in the Create or Update Agenda Item from Document action.
