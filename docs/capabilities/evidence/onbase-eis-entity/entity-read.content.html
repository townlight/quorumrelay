The following schema nodes are available:

Schema Node

Description

ReadEntityType

The name of the operation, followed by the OnBase Entity Type's numeric ID. For example, ReadEntityType_25957.

Expand to display EntityReadData.

EntityReadData

Expand to display entityItemID.

entityItemID

The Entity Item's numeric ID.
Note:

The response schema for this operation includes the all of the Entity Type's fields. Elements for primary key fields are also included if they exist.
