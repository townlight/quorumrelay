Enhancements Release 7.69

September 27, 2026

Numbering

We've drastically upgraded the ability of our auto numbering functionality

Click to Watch Lesson

  1. There is now a "Record Type" built in field that can be used when creating new items. This field can then be associated with specific numbering schemes you have set up to apply certain numbering styles based on the type of item.
  2. We've now given you the ability to choose if you want the year in the numbering scheme and also if you want a 2 or 4 digit year code.
  3. You can also easily include month in the numbering scheme with additional option if you want the number to reset back to 1 at the beginning of each month on it's own.
  4. You can even have a catch all numbering scheme so when an item is created it will check if there is a specific numbering scheme to use or the catch all instead.
  5. These numbers are searchable via internal and public portal.
  6. Besides the automated numbering admin users can go into a topic's properties and manually adjust the number to whatever they want (with audit trail logging of the manual change)
  7. Both Record Type and the custom number can be utilize for dynamic injection into your reports

Misc

  • When pasting or inserting a new table into our editor it will enable the table caption by default
  • When pasting content from Word that has bookmarks our editor will now strip those out automatically
  • On the voting output UI the color you set the font too will also now apply to the border color underneath the logo and title where previously it was static set to a dark grey color
  • Publish email notifications now use the "Meeting Type" field vs the standard name of the board
  • For video teams using chaptering within Cablecast our api call now only sends chapter markers for items that were pulled from Consent instead of all items within Consent

Bugs

  • Copying and Pasting into Personal Notes and Play by Play would prompt you and then close and not save the information.

Live Meetings

This release contains a number of major enhancments for running live meetings in addition to the functionality added you will also notice some UI design enhancements as well.

  • There is now the ability from the meeting building view to check a box for any consent items that you know are going to be pulled ahead of time.

In addition each item within the list has a checkbox allowing you check items you know are going to be removed during the meeting. When checking the box it then moves that topic up with the others resulting in a much easier workflow to take action on independantly.

  • If you log a member out of the meeting; voting results now automatically shows them as absent and records an absent vote in your minutes. There's no longer the need to keep them in the meeting and click their picture to record them as absent during votes.

  • Introducing Multi Topic Voting You can now enable a multi-select mode using the "Multi-Vote" button at the top left. Once enabled, you can check the boxes next to any regular agenda item and vote on all of them at the same time. There's a new modal that appears to manage the motions and start the vote. When voting the board members can see all the items they will be voting on as well as the motion type. The voting results also showcase the numbers and titles of all the items that were voted on.

Linked files themselves are not available to the public, however when you publish an agenda and you have the linked file set as available to the public, as long as that file is word, excel, or powerpoint, it will be converted to a pdf (via Microsoft Graph) and added as a new attachment to the topic with public availablity and inclusion with the packet.

Please note that this conversion adds extra time to packet generation.

Approvals

You can now specify an approval list that applies to any board not listed. So instead of having to add each and every board to an approval you can simply add this new option, specify an approval list and it will use that.
If say you have an approval flow listed for city council it's smart enough to know to use that list of approvers instead of the one designated for the boards not listed.

Signatures
