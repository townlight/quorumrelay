Upload Video (JSON REST API – version 1)

URL

Method URL Content Type
POST https://connect.telvue.com/api/v1/assets/upload/ multipart/form-data

Authentication

Type Credentials Required
HTTP Basic Any user in your Connect account

Parameters

Parameter Type Required Max Length Description
files[] String/Array The file(s) on your drive.
published String/Boolean optional Passing “true” or “t” will publish the video if the user performing the action has permissions. If your organization uses moderation and the user performing the action is moderated, the video will be submitted for moderation. To approve moderated videos, make a moderation request API call.
syndicated String/Boolean optional “true” or “t” will syndicate the video upon upload, defaults to false
syndication_groups String/Array optional Syndication groups you wish to syndicate to by name or access_key. A mix of names and access keys can be passed. To remove video from syndication groups, pass an empty array: “syndication_groups[]=[]“

Examples

Using your favorite HTTP tool or library, make a POST request to https://connect.telvue.com/api/v1/assets/upload and include HTTP Basic Authentication credentials for any user in your Connect account.

cURL

The popular cURL tool comes bundled with any Linux, Mac, or UNIX operating system, and there are Windows equivalents.

Assuming you have a Connect user account, “jsmith”, with the password, “pass”, and a video called “MyVideo.mp4″ in the current directory:

curl -F "files[]=@MyVideo.mp4" --user jsmith:pass \
https://connect.telvue.com/api/v1/assets/upload

Log in to Connect as that user, visit the “My Media” page, and you will see the uploaded video.

Ruby

Here is an example in Ruby 1.9+ using the REST-Client gem (gem install rest-client). Change user, password, and file accordingly:

require 'rubygems'
require 'rest-client'
 
request = RestClient::Request.new(
  method: :post,
  url: 'https://connect.telvue.com/api/v1/assets/upload',
  user: 'jsmith',
  password: 'pass',
  payload: {
    multipart: true,
    file: File.new('MyVideo.mp4', 'rb')
  }
)
response = request.execute

Security

Encryption

Types Required
SSL 3, TLS 1, 1.1, & 1.2

All data sent to and from Connect is secured with SSL/TLS over the HTTPS protocol. Requests made to unsecured http:// URLs are redirected to their https:// equivalents. When accessing the API, make sure your requests are to the https:// URLs. Your client library will seamlessly perform the SSL negotiation.

Passwords

The user’s password, although visible in the code examples above, is not sent in plain text. Like the video you are uploading, SSL also encrypts the password.
