# QuorumRelay core coverage and remaining gaps

Current immutable development snapshot: `0.1.0.dev5`, schema `2.0.0`. Its fresh installed wheel passed the standalone package checks and all 34 original-output comparisons; consumer and live-provider acceptance remain separate. This is a source-path and acceptance map, not a completion or independent-review claim. It preserves all 31 families, 34 baseline inputs and every supported outbound obligation. The capability inventory remains the per-operation research authority; this map describes the current engine and gaps revealed by inspecting its actual paths.

## Shared implemented behavior

All 34 pinned baseline captures retain the original compatibility-reader contract, IDs/namespaces and capture hashes. All 31 imported provider families have deterministic metadata/supplied-text search checks. Neutral JSON/JSONL/ZIP round trips, hash manifests, CSV/iCalendar projection losses, optional scoped SQLite/state extensions, import preview/idempotence, text extraction and exact-plan write coordination are implemented. These generic checks do not prove complete live source text or every vendor operation.

Runtime `providers` reports fifteen additive parser hooks separately from the 34 baseline formats. Identity, capture hash, normalized hash, source revision and consumer destination identity remain distinct. Configured attachment downloads use captured relationships, current policy, exact origins and separate transfer limits.

## Known executable gaps with a documented route

- **Implemented after dev3:** Standalone Legistar supplied Votes/RollCalls collections and details preserve raw captures, per-person values, revisions and parent agenda-item links. Bounded public reads of the existing Olympia tenant returned seven records each over three pages, plus matching details (`legistar-related-reads-2026-11-11.json`). These reads do not establish remote write acceptance.
- **Implemented after dev3:** Laserfiche Repository v2 direct-folder children discovery follows exact-folder provider nextLinks with explicit account repository configuration and OAuth context. Contract-shaped tests cover pagination, namespace/scope isolation, unknown-field/raw preservation and denied access. No authorized account token is available for live acceptance; no WebLink account mapping is inferred. Opt-in guarded WebLink browser/session is now implemented separately; public Louisville/Boulder checks remain blocked.
- **Provider-specific file exports:** CivicPlus Select historical preparation maps canonical Agenda, Agenda Packet, Minutes, Notice and Other PDFs plus one Media MP4 to exact original files and a hash/loss manifest. The vendor-linked tester checks full-filename file-type classification; conflicting names fail. PDF structure, bounded MP4 box framing, scoped input/output grants, duplicates and local bounds are checked. Playback, consultant processing and vendor intake acceptance remain unverified. No FTP transfer occurs. Other unmapped `provider_specific=true` exports remain explicit implementation gaps; they cannot silently substitute a neutral bundle.

- **Implemented after dev3:** Essential dev API reads and full multimedia updates plus TelVue Connect documented GET routes have synthetic source tests in `tests/test_account_apis.py`. Unknown Essential detail/collection schemas remain raw partial responses, and no account list stride/end condition or native search semantics is invented. Trusted credentials bind explicit origin, caller tenant and application namespace; live account access/readback remain unrun.

## Research and environment dependencies

- Generic configured-page paths still need per-provider complete listing/detail/paging evidence, not more repetitions of the same baseline parser test. NovusAGENDA now traverses the observed public listing window, while full archive/search/detail contracts remain unresolved. The BoardDocs interactive portal remains an unresolved automatic route; Tyler has an observed explicit calendar POST but no nonempty live response/paging proof.
- Native search is implemented for Legistar body metadata and Wistia media/transcript excerpts only. Other verified usable provider search contracts require investigation and implementation; unknown routes cannot be relabeled unsupported merely to close the roster.
- Every implemented remote write still needs authorized test credentials/permissions, any tenant-specific required enum values, actual readback and a receipt. No public municipality was mutated. Official docs and synthetic wire/lifecycle checks do not establish those outcomes.
- The optional GuardedWebLinkSession concretely fulfills browser requests through guarded PublicTransport with exact repository/origin/method boundaries. Root recorded focused real-browser, legacy traversal and transport passes and blocked live Louisville/Boulder outcomes in `weblink-guarded-session-2026-11-11.json`; no full live discovery acceptance is claimed.
- Wistia authenticated reads/search/captions need an account test token. Caption-only access may produce an empty visible track list under limited delegation; that is reported as partial visibility, not proof the media has no captions.
- Reference-product persistence, roles, large document jobs, migrations, actual Windows installed workflows, signed installers where delivered, published packages/docs and post-delivery checks are owning integration/delivery outcomes. Passing core tests or a private source commit does not close them.

Historical development wheels and their receipts remain immutable snapshots; dev5 identifies the current build in `verification/quorumrelay-development-05.json`; dev4 and earlier receipts remain historical snapshots.
