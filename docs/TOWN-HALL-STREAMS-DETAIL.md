# Town Hall Streams event/player capture

Configure an explicitly supplied event with `Source("town-hall-streams", "https://townhallstreams.com/stream.php?location_id=72&id=74003", input_format="town-hall-streams-event-html")`. Saved HTML works through `engine.normalize(source, html_bytes, input_format=source.input_format)`; `engine.fetch(source)` performs one bounded configured GET. This does not change the original town/archive compatibility reader.

The event page must declare the requested location/event pair and contain one title/date header whose Back link points to that same town. Native event ID and location namespace remain compatible with the archive records. The displayed date/start time is local and has unknown timezone; the displayed end-time text is retained without inventing an end date. Exact HTML remains in the capture and original record.

The captured vendor player declares `var originalFile = "..."`, passes it through `thsPlayableHlsUrl(originalFile)`, then assigns the resolved file to the player. The mapping decodes only a JSON string literal; it does not evaluate JavaScript. A unique HTTPS, query-free, fragment-free `cdn.townhallstreams.com/vod/.../playlist.m3u8` declaration is exposed as the player recording's `playback_url`, with its provenance and `media_bytes_verified: false`. The original `stream.php` player remains `url`. Ambiguous, foreign or unverified locators leave the meeting/player intact without a playback URL. No MP4 address is derived from the path, and player caption settings are not transcript data.

To retrieve the supplied playlist, explicitly configure `options={"download_origins": ["https://cdn.townhallstreams.com"]}` and call `engine.fetch_attachment(source, record, kind="recordings", url_field="playback_url", capture=html_bytes)`. Existing network, namespace, deadline and transfer limits apply. A returned HLS playlist is not verification of its segments, playable video or a complete recording. This package does not recursively download HLS segments or add a transcoder. Transcript AJAX declarations and hidden controls are never invoked by this mapping.

Evidence: eight synthetic saved/configured engine and boundary cases; one existing 31,913-byte event capture normalized offline. No new live request, segment download, transcript fetch or provider mutation occurred. Configured results remain partial with no archive/catalog completeness claim. Vendor create/update/upload contracts remain separate unresolved work.
